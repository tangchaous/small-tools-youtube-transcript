Obsidian vaults

Install the Local REST API community plugin in each vault, then copy its API key here. Use http://127.0.0.1:27123 after turning on Enable Non-encrypted (HTTP) Server in the plugin settings, or https://127.0.0.1:27124 if you have trusted the plugin's certificate. The plugin writes to whichever vault it runs in, so each vault needs its own key (and port, if several vaults are open at once). Name each profile exactly like the vault so "Open in Obsidian" links work.
